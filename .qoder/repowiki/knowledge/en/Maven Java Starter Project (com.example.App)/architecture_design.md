Single-package Java application under `src/main/java/com/example` with the `App` class exposing a `main` method and a static `greet` helper. Tests live in the conventional `src/test/java/com/example/AppTest.java` using JUnit Jupiter. The project is built via Maven (`pom.xml`) targeting Java 17, with no external runtime dependencies beyond JUnit for testing; packaging produces a plain JAR.
